Introduction to Networking

A comprehensive guide to networking fundamentals and best practices

Instructor: Brendan Shea, PhD — Rochester Community and Technical College

Welcome to the Course

This course provides a comprehensive introduction to networking fundamentals. Designed for students new to IT and networking, the materials cover foundational concepts, protocols, and operational practices used in real-world networks.

Through eleven progressive modules, you'll explore the OSI model, network topologies, IP addressing, routing, security concepts, and operational best practices. Each module includes both an interactive HTML chapter and downloadable PDF lecture slides.

Course Overview

What You'll Learn

  • Network fundamentals & OSI model
  • IP addressing, subnetting & routing
  • Network services & applications
  • Operations, monitoring & troubleshooting
  • Security, hardening & access control

Access Methods

  • Interactive HTML chapters with Mermaid diagrams
  • Downloadable PDF lecture slides
  • Embedded code examples & tables
  • Mobile-friendly responsive design

Course Structure

  • 11 progressive modules
  • Foundation to advanced topics
  • CompTIA Network+ aligned
  • Case studies & real-world examples
