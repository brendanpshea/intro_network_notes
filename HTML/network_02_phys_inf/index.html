Module 2

Physical Layer and Cabling

Copper, fiber, structured cabling, environmental controls, and physical-layer troubleshooting.

Introduction

This chapter focuses on Layer 1, the physical layer. If the cable does not work, nothing above it matters. That means we need to understand how bits move across wires, what different cable types are for, how to install them correctly, and how to troubleshoot them when they fail.

The physical layer is where networking becomes tangible: copper pairs, fiber strands, racks, patch panels, connectors, cooling, and power. It is also where installation mistakes are easiest to make and often hardest to diagnose later.

Review from Module 1

Module 1 introduced the OSI model. This chapter picks up at Layer 1, where data is represented as electrical or optical signals rather than frames or packets.

Layer 1 Reminder

If the signal is broken, no amount of addressing, routing, or application logic can fix it.

Learning Outcomes

After completing this module, you will be able to:

  • Explain how bits travel as electrical signals or light pulses.
  • Compare UTP, STP, coaxial, twinax, and fiber cabling.
  • Select the proper category rating, connector, and wiring standard for a run.
  • Distinguish MMF from SMF and choose the right fiber type for a distance.
  • Apply structured cabling and termination best practices.
  • Identify environmental and safety requirements for physical installations.
  • Troubleshoot physical-layer faults using the right tools.

Physical Layer Fundamentals

Physical Layer Fundamentals

How Does Data Travel on a Wire?

Computers represent data as bits. On copper cables, bits are carried as voltage changes. On fiber, they are carried as light pulses. The key idea is simple: a physical medium has to represent 1s and 0s in a way that the receiver can reliably interpret.

Baseband Signaling

Ethernet uses baseband signaling, meaning one signal occupies the cable at a time rather than dividing it into many separate channels.

Half-Duplex vs Full-Duplex

Duplex mode describes whether devices can transmit and receive at the same time. Half-duplex allows only one direction at a time and was common with hubs. Full-duplex allows simultaneous send and receive and is standard on modern switched Ethernet.

Half-Duplex

One side transmits while the other listens. If both try to speak at once, the result is a collision.

Full-Duplex

Both ends can transmit at the same time. No collisions, better throughput, and better efficiency.

Ethernet Standards

Ethernet standard names encode speed, signal type, and cable type. Once you can read them, standards like 100BASE-TX and 10GBASE-SR become easy to interpret.

Reading 100BASE-TX

100 = 100 Mbps, BASE = baseband, T = twisted pair copper, TX = an Ethernet variant for copper media.

Collisions: A Problem We Solved

Early Ethernet shared one collision domain. If two devices transmitted at the same time, the signals collided. Hubs created this problem; switches solved it by giving each port its own collision domain.

Ethernet Speeds: Then and Now

Ethernet has advanced from 10 Mbps to 100 Gbps and beyond. Each leap in speed has typically demanded better cabling, tighter specifications, and more capable hardware. 

graph LR
    A["10BASE-T\n10 Mbps"] --> B["100BASE-TX\n100 Mbps"] --> C["1000BASE-T\n1 Gbps"] --> D["10GBASE-T\n10 Gbps"] --> E["40/100G\nData center"]

Figure 6: Ethernet speed evolution. Faster standards require tighter cabling and better signal integrity.

Why Do Faster Speeds Need Better Cables?

Faster signaling means more bits per second, which makes the signal more sensitive to attenuation, crosstalk, and EMI. Good cabling keeps the signal recognizable; poor cabling turns clean transitions into noise.

Good Cable

Clean transitions, low noise, and a receiver that can clearly distinguish 1s from 0s.

Poor Cable

Degraded transitions, more noise, and a much higher chance of errors or retransmission.

    G["Clean signal"] --> H["Receiver reads bits correctly"]
    P["Noisy signal"] --> Q["Receiver sees errors"]

Figure 7: Better cables preserve signal quality. Poor cables distort the waveform and make high-speed links unstable.

Copper Cabling

Copper Cabling

Twisted Pair Technology

Twisted pair cable works because twisting the conductors helps cancel out interference. The two wires in a pair experience roughly the same noise, so the receiver can subtract the noise and recover the intended signal. 

graph LR
    A["Wire A"] --- B["Wire B"]
    N["Noise affects both wires similarly"] --> R["Receiver subtracts noise"]

Figure 8: Twisted pair reduces EMI and crosstalk by exposing both conductors to similar noise.

Unshielded Twisted Pair (UTP)

UTP is the most common network cabling type. It uses four twisted pairs and no metal shielding. It is inexpensive, flexible, and easy to terminate, which makes it the default choice for most offices and homes.

UTP Strengths and Limits

UTP is cheap and flexible, but it is more sensitive to strong EMI than shielded cable.

Shielded Twisted Pair (STP)

STP adds shielding for harsher environments. It is useful near motors, fluorescent lighting, factories, and other strong sources of interference. If shielding is used, it must be grounded correctly.

Grounding Matters

Un-grounded shielding can behave like an antenna and make the problem worse.

Category Ratings

Cable categories describe performance. Higher numbers mean tighter tolerances and better performance at higher frequencies.

Rule of Thumb

For new installations, Cat6a is the safest practical choice because it supports 10 Gbps at 100 meters.

The RJ-45 Connector

RJ-45 is the common Ethernet plug, technically an 8P8C connector. It is used on copper cabling and requires proper crimping or termination to function reliably. 

graph LR
    C["RJ-45 / 8P8C"] --> P["8 pins\n4 wire pairs"]
    C --> T["Tab/clip locks the plug in place"]

Figure 9: RJ-45 connectors use eight positions and eight contacts. Good terminations matter.

RJ-45 vs RJ-11

RJ-11 is smaller and used for telephone lines. Do not force a phone connector into an Ethernet port.

Plenum, Coax, and Twinax

Not all copper cable is twisted pair. Some environments require plenum- or riser-rated cable for fire safety. Coaxial cable is still used for cable internet and legacy CCTV, while twinaxial cable is common for short direct-attach links in data centers.

Plenum and Riser

Plenum cable is required in air-handling spaces. Riser cable is designed for vertical runs between floors.

Coax and Twinax

Coax uses a single center conductor and shielding. Twinax uses two conductors and is popular for DAC links.

Structured Cabling Systems

Structured Cabling Systems

Organizing the Chaos

Structured cabling organizes building cabling into a manageable system of distribution frames, patch panels, and standardized runs. The goal is to make moves, adds, and changes easy without disturbing the permanent wiring. 

graph TD
    MDF["fa:fa-server MDF"] --> IDF["fa:fa-network-wired IDF"]
    IDF --> J["fa:fa-wall-brick Wall Jack"]

Figure 10: Structured cabling uses a backbone from the MDF to each IDF and horizontal runs from the IDF to wall jacks.

T568A and T568B Wiring Standards

T568A and T568B are the two accepted pinout standards for RJ-45 terminations. Both work correctly as long as you use the same standard on both ends of a straight-through cable.

T568A

Common in government installations and legacy environments.

T568B

Most common in commercial installations.

Critical Rule

Use the same standard on both ends of a straight-through cable. Mixed standards create crossover wiring.

Straight-Through vs Crossover Cables

graph LR
    A["T568B"] --> S["Straight-through\nlike devices"] --> B["T568B"]
    C["T568A"] --> X["Crossover\nunlike devices"] --> D["T568B"]

Figure 11: Straight-through cables use the same pinout on both ends. Crossover cables use different pinouts and are now rarely needed because of auto-MDI-X.

Auto-MDI-X

Most modern switches and NICs detect cable type automatically, which makes crossover cables largely obsolete.

Patch Panels

Patch panels terminate permanent building cabling in one place. Short patch cords then connect the panel to network equipment, keeping the building cabling stable and organized.

Why Patch Panels Help

Moves and changes happen on patch cords instead of the permanent in-wall runs.

Termination Tools

Crimping Tool

Attaches RJ-45 connectors to cable ends. Bad crimps are a common source of problems.

Punchdown Tool

Seats wire into patch panels and keystone jacks. The excess conductor is cut automatically.

Cable Installation Best Practices

Good installation practices prevent expensive troubleshooting later. Respect bend radius, keep cable away from power, label both ends, and follow the 90/10 rule for horizontal cabling.

Do This
  • Maintain proper bend radius
  • Cross power cables at 90 degrees
  • Label both ends
  • Test each cable after termination
Don’t Do This
  • Do not sharply bend cable
  • Do not exceed pull tension
  • Do not untwist pairs too far
  • Do not leave runs unlabeled

Fiber Optic Cabling

Fiber Optic Cabling

Why Fiber Optic?

Fiber transmits light instead of electricity. That makes it immune to EMI, capable of much longer distances, and well suited for high-speed uplinks and between-building runs. It costs more and requires more specialized termination, but it solves problems copper cannot.

Choose Fiber When...

You need more than 100 meters, want immunity to EMI, need a building-to-building link, or want a harder-to-tap medium.

Fiber Optic Cable Structure

Fiber has a core where light travels, a cladding layer that reflects light back inward, a protective coating, and an outer jacket. The cladding has a lower refractive index than the core so total internal reflection can keep light inside. 

graph TD
    C["Core"] --> L["Cladding"] --> P["Buffer coating"] --> J["Jacket"]

Figure 12: Fiber cable anatomy. The cladding keeps light trapped in the core through total internal reflection.

Single-Mode vs Multimode Fiber

Multimode Fiber (MMF)

Shorter distances, larger core, lower cost. Common for building-scale links.

Single-Mode Fiber (SMF)

Long distances, tiny core, more expensive optics. Common for campus or WAN links.

TypeCoreDistanceJacketBest For

Fiber Splicing and WDM

Fiber splicing joins fiber ends permanently or semi-permanently. Wavelength division multiplexing lets multiple light colors ride on one strand at the same time.

WDM

WDM is like sending different colored flashlights down the same fiber. Each wavelength carries separate data.

Case Study: Wednesday’s Cemetery Office

Case Study — Wednesday’s Cemetery Office

Wednesday needs a 300 meter connection to her office. Uncle Fester wants to use Cat6a through electrical conduits. Lurch recommends fiber.

Review questions:

  1. Can Cat6a reach 300 meters?
  2. What two advantages does fiber have here?
  3. Should she choose MMF or SMF?
Solution — Wednesday’s Cemetery Office
  1. No. Cat6a maxes out at 100 meters.
  2. Fiber handles 300 meters easily and is immune to EMI from the electrical lines.
  3. MMF is enough because 300 meters is well within its range and the optics are cheaper.

Network Infrastructure

Network Infrastructure

Rack Systems

Equipment racks keep devices organized, accessible, and cool. Rack size is measured in rack units, where 1U equals 1.75 inches. Two-post racks are common for patch panels and lighter gear, while four-post racks or cabinets support heavier equipment.

Rack SizeTypical Equipment
1UPatch panels, small switches
2ULarger switches, UPS units
4UServers, storage equipment

Environmental Factors

Temperature, humidity, and airflow matter as much as the hardware itself. Too hot means overheating. Too cold can produce condensation. Too dry increases static. Too humid increases corrosion risk.

Hot Aisle / Cold Aisle

Data centers separate cold intake air from hot exhaust air so heat does not recirculate into equipment.

Power Management

UPS devices provide battery-backed power and conditioning. PDUs distribute power in the rack. Grounding matters, and circuits should not be overloaded.

Plan Before You Plug In

Sum the wattage and leave headroom so you do not overload circuits or UPS capacity.

Fire Suppression

Server rooms should use clean agents or pre-action sprinklers, not ordinary water sprinklers. For electrical equipment, use Class C or ABC-rated extinguishers nearby.

Safety First

Equipment can be replaced. People cannot.

Cable Testing and Troubleshooting

Cable Testing and Troubleshooting

Common Cable Problems

Physical-layer problems include attenuation, EMI, crosstalk, opens, and shorts. In many cases, the root cause is not the cable category itself but a bad termination or damaged connector.

Most Common Problem

Bad terminations cause a surprising number of cable failures. If a link is intermittent, inspect both ends first.

Cable Testing Tools

Basic Tools
  • Cable tester
  • Wire map tester
  • Tone generator and probe
Advanced Tools
  • TDR for copper
  • OTDR for fiber
  • Certification tester
  • Visual fault locator

Advanced Testing Tools

Basic testers tell you whether conductors are connected. Advanced tools tell you where a problem is, how far down the cable it occurs, and whether the cable meets the category standard.

Case Study: Pugsley’s Flickering Connection

Case Study — Pugsley’s Flickering Connection

Pugsley’s connection drops whenever the patch panel cable is moved, even though the cable tester says all eight wires have continuity.

  3. What tool would identify the problem most clearly?

Module Summary

Module Summary

Module 2 Summary

Copper and Signals

  • Layer 1 sends bits as voltage changes or light pulses.
  • Twisted pair is the standard copper medium because twisting helps reject noise.
  • Cat5e is enough for 1 Gbps; Cat6a is the safer choice for 10 Gbps.
  • RJ-45 is the common Ethernet connector on copper cabling.

Installation Basics

  • Use plenum cable where code requires it.
  • Respect bend radius and the 90/10 rule.
  • Use patch panels and label everything.

Fiber and Infrastructure

  • MMF is for building-scale runs; SMF is for long-distance runs.
  • LC connectors dominate modern fiber installs.
  • Racks, cooling, power, and fire suppression all affect uptime.
  • Test cables with the right tool for the problem.

Troubleshooting

  • Bad terminations are common.
  • Continuity testing is not the same as certification.
  • Layer 1 problems must be fixed before higher-layer troubleshooting matters.
